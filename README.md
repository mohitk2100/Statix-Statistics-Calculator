# Statix-Statistics-Calculator
Statix is a web-based statistics calculator designed to make statistical calculations easier, more interactive, and easier to understand. It helps users solve statistical problems, visualize data, and understand calculations through step-by-step explanations.

Web-https://statixcal.lovable.app/calculator

Features
Calculate Mean, Median, and Mode.
Generate graphs and data visualizations.
Create frequency tables and statistical summaries.
Understand calculations through step-by-step explanations.
Import CSV files for data analysis.
Download calculation results.

Purpose
The goal of Statix is to simplify statistics for students and learners by combining calculations, visualizations, and clear explanations in one user-friendly application.

Built With
Lovable
AI-assisted development

Project Status
Developed as a learning project focused on statistics, data visualization, and building practical web applications.
